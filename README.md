*3 Nether portals in a superflat world. From left to right: Nether portal, a portal built with both obsidian and crying obsidian, and a portal built entire with crying obsidian. 

### Overview
**Crying Portals** is a very simple mod that allows crying obsidian blocks to be used as blocks to form the frame of Nether portals, and will light and function as normal.

Portals using crying obsidian will still spawn their matching Nether portal in the other dimension *without crying obsidian*, as they are simply the default portals.
